# Retail Sales Analytics — End-to-End Data Analyst Portfolio Project

## Overview
This project demonstrates an end-to-end retail analytics workflow using **Python, pandas, SQL and data visualisation**. It covers data quality checks, cleaning, KPI creation, category/channel/region analysis, time trends, and a written summary.

**Important:** The included dataset is synthetic and generated for this portfolio project. It does not represent a real retailer or real customer transactions. All findings are illustrative.

## Business questions
- How do revenue and profit change over time?
- Which product categories contribute the most revenue and profit?
- How do online, in-store and marketplace channels compare?
- Which regions contribute most to revenue?
- How do average revenue and profit vary by discount level?

## Run locally
1. Clone or download this repository.
2. Install Python 3.10 or later.
3. Create and activate a virtual environment (recommended).
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the analysis from the repository root:
   ```bash
   python src/analyze_retail.py
   ```
6. Review the generated CSV files, charts and `outputs/analysis_summary.md`.

## Data cleaning and validation
The script:
- parses order dates and numeric columns;
- standardises text fields;
- excludes records with invalid dates, non-positive quantity or price, negative unit cost, or invalid discount rates;
- retains rows with missing dimensions by labelling them `Unknown`;
- recalculates revenue and profit consistently from quantity, unit price, cost and discount;
- creates month-level data for trend analysis.

## Outputs
- `retail_sales_clean.csv`: cleaned dataset with derived columns.
- `monthly_kpis.csv`: monthly revenue, profit, order count and units sold.
- `category_performance.csv`: revenue, profit, units and profit margin by category.
- `channel_performance.csv`: sales channel KPIs.
- `regional_performance.csv`: regional KPIs.
- `discount_analysis.csv`: descriptive discount-level metrics.
- `charts/`: visualisations generated by the script.
- `analysis_summary.md`: automatically generated KPI summary and interpretation notes.

## SQL
Example SQL queries are included in `sql/retail_analysis_queries.sql`. They use PostgreSQL-style `DATE_TRUNC`; adjust date syntax if using a different database.

## Limitations
- Synthetic data is suitable for demonstrating an analytical workflow but not for making real business decisions.
- The discount analysis is descriptive and does not establish causal effects.
- The project does not model returns, tax, shipping, inventory constraints or customer lifetime value.
- In real work, confirm KPI definitions and data provenance with stakeholders.

## Possible extensions
- Add a Power BI dashboard using the cleaned CSV and KPI tables.
- Load the cleaned dataset into PostgreSQL or SQLite and run the SQL queries.
- Add unit tests for the cleaning and KPI functions.
- Add cohort analysis, repeat-purchase rates and a documented forecasting baseline.
